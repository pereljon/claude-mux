# claude-mux - Мультиплексор Claude Code

Постоянные сессии Claude Code для всех ваших проектов - доступные откуда угодно через мобильное приложение Claude. ***Управляется Claude!***

## Установка

```bash
curl -fsSL https://github.com/pereljon/claude-mux/releases/latest/download/install.sh | bash
```

Затем запустите сессию:

```bash
claude-mux ~/path/to/your/project
```

Установщик спрашивает, хотите ли вы home-сессию при входе в систему. Если вы соглашаетесь, защищённая сессия Claude запускается автоматически при каждом входе - всегда доступная с телефона или любого клиента Remote Control, даже если вы не открываете терминал.

Всё. Вы находитесь в постоянной сессии Claude с поддержкой контекста и включённым Remote Control. **Дальше всё делается через разговор.**

[Homebrew, ручная установка и другие варианты](../docs/INSTALL.md)

## Зачем это нужно

Remote Control обещает Claude Code отовсюду - но без управления сессиями это интерфейс второго сорта даже из Claude Desktop:

- **Сессии завершаются** при закрытии терминала - и не возвращаются после сбоя или перезагрузки
- **Контекст разговора** не возобновляется автоматически
- **Нет постоянной точки доступа** - ничего не запущено, когда вы берёте телефон, если только вы не оставили что-то открытым
- **Remote Control требует запущенную сессию** - запустить её из RC нельзя
- **Слэш-команды не работают в RC-сессиях** - нет смены модели, сжатия контекста или изменения режима разрешений
- **Создание новых проектов** - требует вручную создать директорию, инициализировать git, написать файл инструкций (AGENTS.md или CLAUDE.md) и выбрать модель
- **Нет управления проектами** - нет способа увидеть неактивные проекты, переименовать, переместить или удалить проекты без потери истории

**claude-mux устраняет пробел в управлении сессиями.** Он оборачивает Claude Code в tmux, чтобы сессии не прерывались, автоматически восстанавливает их после сбоев и перезагрузок (если включён автоматический вход), внедряет системный промпт, чтобы Claude мог управлять собственными сессиями, и маршрутизирует слэш-команды через tmux, чтобы они работали через Remote Control. Как только сессия запущена, вы управляете всем, разговаривая с Claude - в терминале или через мобильное приложение.

## Что можно делать в сессии claude-mux

- **Переживает сбои и перезагрузки** - сессии автоматически восстанавливаются при повторном входе и продолжают последний разговор. Обычный `/exit` или выключение оставляет сессию остановленной; сессия, которая падает в цикле, останавливается и помечается, а не перезапускается бесконечно.
- **Управлять любой сессией из любой сессии** - запускать, останавливать, перезапускать, просматривать и сжимать проекты на естественном языке
- **Доступ ко всему отовсюду** - у каждой сессии включён Remote Control, поэтому мобильное приложение Claude, десктопное приложение или любой удалённый клиент является полноценным интерфейсом
- **Переключать модели и режимы разрешений** - скажите "switch to Haiku" или "switch to plan mode", и Claude всё сделает, даже через Remote Control
- **Создавать новые проекты** - "create a new project called my-app" настраивает директорию, git, AGENTS.md из шаблона и запускает сессию. Шаблоны позволяют повторно использовать инструкции между проектами.
- **Отправлять слэш-команды через Remote Control** - Claude маршрутизирует `/model`, `/compact`, `/clear` и другие слэш-команды к запущенной сессии, обходя [известное ограничение](https://github.com/anthropics/claude-code/issues/30674). RC переподключается автоматически после `/compact` через хук `PreCompact`.
- **Обнаружение обновлений Claude Code** - когда бинарный файл `claude` меняется (после `brew upgrade` или обновления npm), запущенные сессии показывают уведомление о перезапуске для загрузки нового бинарного файла; уведомление сохраняется между запросами, пока вы не перезапустите сессию, поэтому пропущенный ход его не теряет
- **Сохранять историю разговоров** - переименование, перемещение и перезапуск проектов автоматически сохраняют историю
- **Организовывать проекты** - скрывать, переименовывать, перемещать, удалять и защищать проекты изнутри любой сессии
- **Поддержка нескольких аккаунтов GitHub** - обнаруживает SSH-алиасы в `~/.ssh/config` и внедряет их в сессии, чтобы Claude использовал правильный аккаунт для каждого проекта
- **AGENTS.md как файл инструкций проекта** - `AGENTS.md` единственный настоящий файл, его читают Claude Code и Codex CLI. Скажите "migrate to AGENTS.md", чтобы преобразовать существующее дерево из `CLAUDE.md` (сначала отчёт, ничего не коммитится). Требуется Claude Code 2.1.277 или новее; в более старых версиях остаётся `CLAUDE.md`. Gemini CLI читает его только если в `~/.gemini/settings.json` есть `"context": {"fileName": ["AGENTS.md"]}`.
- **Работает на любом языке** - диалоговые команды определяются по намерению, а не по ключевым словам

## Разговор с Claude

Именно так используется claude-mux в повседневной работе. В каждую сессию внедряются команды, позволяющие Claude управлять сессиями, переключать модели, отправлять слэш-команды и создавать новые проекты - всё из разговора. Запоминать CLI-флаги не нужно.

```
Скажите: "status"
Сообщает имя сессии, модель, режим разрешений, использование контекста и список всех сессий

Скажите: "покажи активные сессии"
Показывает все запущенные сессии с их статусом

Скажите: "покажи неактивные сессии"
Показывает только неактивные проекты

Скажите: "покажи остановленные сессии"
Показывает только остановленные сессии

Скажите: "запусти сессию для моего проекта api-server"
Запускает сессию по имени; ничего не делает, если она уже запущена

Скажите: "создай новый проект mobile-app с шаблоном web"
Создаёт каталог проекта, инициализирует git, применяет шаблон, запускает сессию

Скажите: "переключи эту сессию на Haiku"
Определяет последний конкретный ID для семейства и отправляет /model claude-haiku-4-5 самой себе

Скажите: "сожми сессию api-server"
Отправляет /compact в сессию api-server

Скажите: "перезапусти сессию web-dashboard"
Завершает и перезапускает сессию, сохраняя контекст разговора

Скажите: "перезапусти эту сессию с чистого листа"
Просит подтверждения, затем перезапускает с новым разговором - без возобновления, без прежнего контекста

Скажите: "убей сессию api-server"
Просит подтверждения, затем очищает разговор и останавливает сессию; следующий запуск начинает новый разговор, а не возобновляет прежний

Скажите: "заверши эту сессию"
Сначала сохраняет незавершённую работу и следующий шаг, просит подтверждения (и спрашивает, нет ли несохранённого), затем перезапускает с чистого листа

Скажите: "переключи сессию api-server в plan mode"
Перезапускает сессию в режиме разрешений plan

Скажите: "переключи эту сессию в yolo mode"
Переключается в режим bypassPermissions через Shift+Tab - перезапуск не нужен

Скажите: "какой режим у этой сессии"
Сообщает текущий режим разрешений (default, acceptEdits, plan, bypassPermissions)

Скажите: "переключи эту сессию на Opus"
Определяет последний конкретный ID для семейства и отправляет /model claude-opus-4-8 самой себе

Скажите: "очисти эту сессию"
Просит подтверждения, затем отправляет /clear самой себе, сбрасывая разговор

Скажите: "скрой этот проект"
Создаёт .claudemux-ignore, чтобы проект не отображался в списках -L

Скажите: "защити эту сессию"
Создаёт .claudemux-protected и устанавливает маркер tmux - для остановки теперь нужен --force

Скажите: "эта сессия защищена?"
Проверяет наличие .claudemux-protected в каталоге проекта и сообщает

Скажите: "удали проект old-prototype"
Уточняет в чате, затем перемещает папку проекта в корзину

Скажите: "переименуй этот проект в my-new-name"
Останавливает сессию, переименовывает папку, переносит историю, перезапускает

Скажите: "сохрани это как шаблон с именем web"
Копирует AGENTS.md (или CLAUDE.md) в ~/.claude-mux/templates/web.md

Скажите: "проверь миграцию на agents" / "перейди на AGENTS.md"
Сообщает (только чтение), какие файлы CLAUDE.md можно перевести на AGENTS.md; после подтверждения переименовывает их по всему дереву и перезапускает запущенные сессии в базовом каталоге

Скажите: "совет"
Выводит совет - один и тот же весь день, или случайный при TIP_MODE=random

Скажите: "включи советы" / "выключи советы"
Включает или выключает совет дня во всех проектах

Скажите: "обнови claude-mux"
Предупреждает о перезапуске всех сессий, спрашивает подтверждение, затем обновляет и перезапускает

Скажите: "останови все сессии"
Корректно завершает все управляемые сессии

Скажите: "help"
Выводит полный список диалоговых команд
```

**Эти команды работают на любом языке.** Если вы напишете то же самое по-испански, по-японски, на иврите или любом другом языке, Claude поймёт намерение и выполнит соответствующую команду.

**Введите `help` внутри любой сессии, чтобы увидеть полный список команд.**
