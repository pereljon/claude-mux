סשנים מתמשכים של Claude Code לכל הפרויקטים שלך - נגישים מכל מקום דרך אפליקציית Claude לנייד. ***מנוהל על ידי Claude!***

## התקנה

```bash
curl -fsSL https://github.com/pereljon/claude-mux/releases/latest/download/install.sh | bash
```

לאחר מכן הפעל סשן:

```bash
claude-mux ~/path/to/your/project
```

תוכנית ההתקנה שואלת אם ברצונך להפעיל סשן home בעת הכניסה למערכת. אם תסכים, סשן Claude מוגן מופעל אוטומטית בכל פעם שאתה מתחבר - תמיד נגיש מהטלפון או מכל לקוח Remote Control, גם אם לעולם לא תפתח טרמינל.

זהו! אתה בסשן Claude מתמשך ומודע-סשן עם Remote Control מופעל. **מכאן, הכל בשיחה.**

[Homebrew, התקנה ידנית ואפשרויות נוספות](../docs/INSTALL.md)

## למה

Remote Control מבטיח Claude Code מכל מקום - אבל בלי ניהול סשנים, זה ממשק מדרגה שנייה גם מ-Claude Desktop:

- **סשנים מתים** כשסוגרים את הטרמינל - ולא חוזרים אחרי קריסה או אתחול
- **הקשר השיחה** לא מתחדש אוטומטית
- **אין בסיס פעולות** - שום דבר לא רץ כשאתה שולף את הטלפון, אלא אם השארת משהו פתוח
- **Remote Control דורש סשן פעיל** - אי אפשר להתחיל אחד מ-RC
- **פקודות slash לא עובדות בסשני RC** - אין החלפת מודל, דחיסה, או שינוי מצב הרשאות
- **התחלת פרויקטים חדשים** - דורשת יצירת תיקייה ידנית, אתחול git, כתיבת קובץ הוראות (AGENTS.md או CLAUDE.md) ובחירת מודל
- **אין ניהול פרויקטים** - אין דרך לראות פרויקטים לא פעילים, או לשנות שם, להעביר ולמחוק פרויקטים בלי לשבור היסטוריה

**claude-mux סוגר את הפער בניהול סשנים.** הוא עוטף את Claude Code ב-tmux כדי שסשנים ישרדו, משחזר אותם אוטומטית אחרי קריסות ואתחולים (כל עוד הכניסה האוטומטית מופעלת), מזריק system prompt כדי ש-Claude יוכל לנהל את הסשנים שלו, ומנתב פקודות slash דרך tmux כדי שיעבדו דרך Remote Control. ברגע שסשן רץ, אתה מנהל הכל בשיחה עם Claude - בטרמינל או באפליקציה לנייד.

## מה אפשר לעשות בסשן claude-mux

- **שורד קריסות ואתחולים** - סשנים משוחזרים אוטומטית כשאתה נכנס שוב, וממשיכים את השיחה האחרונה. `/exit` נקי או כיבוי משאיר את הסשן כבוי; סשן שנכנס ללולאת קריסות נעצר ומסומן, ולא מופעל מחדש לנצח.
- **לנהל כל סשן מכל סשן** - להפעיל, לעצור, להפעיל מחדש, לרשום ולדחוס פרויקטים בשפה טבעית
- **לגשת לכל דבר מכל מקום** - לכל סשן מופעל Remote Control, כך שאפליקציית Claude לנייד, למחשב שולחני, או כל לקוח מרוחק הוא ממשק מלא
- **להחליף מודלים ומצבי הרשאות** - אמור "עבור ל-Haiku" או "עבור למצב plan" ו-Claude מטפל בזה, גם דרך Remote Control
- **ליצור פרויקטים חדשים** - "צור פרויקט חדש בשם my-app" מגדיר את התיקייה, git, AGENTS.md מתבנית, ומפעיל סשן. תבניות מאפשרות שימוש חוזר בהוראות בין פרויקטים.
- **לשלוח פקודות slash דרך Remote Control** - Claude מנתב `/model`, `/compact`, `/clear` ופקודות slash נוספות לסשן הפעיל, עוקף [מגבלה ידועה](https://github.com/anthropics/claude-code/issues/30674). RC מתחבר מחדש אוטומטית אחרי `/compact` דרך hook מסוג `PreCompact`.
- **זיהוי שדרוג של Claude Code** - כשקובץ ה-`claude` משתנה (אחרי `brew upgrade` או עדכון npm), סשנים פעילים מציגים הודעה להפעיל מחדש כדי לטעון את הקובץ החדש; ההודעה נשארת בין הנחיות עד שמפעילים מחדש, כך שתור שהוחמץ לא מאבד אותה
- **לשמור היסטוריית שיחות** - שינוי שם, העברה והפעלה מחדש של פרויקטים שומרים אוטומטית על היסטוריית השיחה
- **לארגן פרויקטים** - להסתיר, לשנות שם, להעביר, למחוק ולהגן על פרויקטים מתוך כל סשן
- **תמיכה במספר חשבונות GitHub** - מזהה SSH aliases ב-`~/.ssh/config` ומזריק אותם לסשנים כדי ש-Claude ישתמש בחשבון הנכון לכל פרויקט
- **AGENTS.md כקובץ ההוראות של הפרויקט** - `AGENTS.md` הוא הקובץ האמיתי היחיד, וקוראים אותו Claude Code ו-Codex CLI. אמור "migrate to AGENTS.md" כדי להמיר עץ קיים מ-`CLAUDE.md` (קודם דוח, שום דבר לא נעשה commit). דורש Claude Code 2.1.277 ומעלה; גרסאות ישנות יותר נשארות עם `CLAUDE.md`. Gemini CLI קורא אותו רק אם ב-`~/.gemini/settings.json` יש `"context": {"fileName": ["AGENTS.md"]}`.
- **עובד בכל שפה** - פקודות שיחה מזוהות לפי כוונה, לא לפי מילות מפתח

## לדבר עם Claude

ככה משתמשים ב-claude-mux יום-יום. כל סשן מוזרק עם פקודות כדי ש-Claude יוכל לנהל סשנים, להחליף מודלים, לשלוח פקודות slash וליצור פרויקטים חדשים - הכל מתוך השיחה. אין צורך לזכור דגלי CLI.

```
אמור: "status"
מדווח על שם הסשן, מודל, מצב הרשאות, שימוש בהקשר, ורושם את כל הסשנים

אמור: "הצג סשנים פעילים"
מציג את כל הסשנים הפעילים עם הסטטוס שלהם

אמור: "הצג סשנים לא פעילים"
מציג רק פרויקטים לא פעילים

אמור: "הצג סשנים שנעצרו"
מציג רק סשנים שנעצרו

אמור: "הפעל סשן לפרויקט api-server שלי"
מפעיל את הסשן לפי שם; לא עושה דבר אם הוא כבר רץ

אמור: "צור פרויקט חדש בשם mobile-app עם תבנית web"
יוצר את תיקיית הפרויקט, מאתחל git, מחיל את התבנית, מפעיל סשן

אמור: "העבר את הסשן הזה ל-Haiku"
מפענח את המשפחה למזהה הקונקרטי העדכני ושולח /model claude-haiku-4-5 לעצמו

אמור: "דחוס את סשן api-server"
שולח /compact לסשן api-server

אמור: "הפעל מחדש את סשן web-dashboard"
מכבה ומפעיל מחדש את הסשן, שומר על הקשר השיחה

אמור: "הפעל מחדש את הסשן הזה מאפס"
מבקש אישור, ואז מפעיל מחדש עם שיחה חדשה - בלי חידוש, בלי הקשר קודם

אמור: "הרוג את סשן api-server"
מבקש אישור, ואז מנקה את השיחה ועוצר אותו; ההפעלה הבאה היא שיחה חדשה, לא חידוש

אמור: "סיים את הסשן הזה"
שומר קודם עבודה לא גמורה ואת הצעד הבא, מבקש אישור (ושואל אם יש משהו שלא נשמר), ואז מפעיל מחדש מאפס

אמור: "העבר את סשן api-server למצב plan"
מפעיל מחדש את הסשן עם מצב הרשאות plan

אמור: "העבר את הסשן הזה למצב yolo"
עובר למצב bypassPermissions דרך Shift+Tab - בלי צורך בהפעלה מחדש

אמור: "באיזה מצב הסשן הזה"
מדווח על מצב ההרשאות הנוכחי (default, acceptEdits, plan, bypassPermissions)

אמור: "העבר את הסשן הזה ל-Opus"
מפענח את המשפחה למזהה הקונקרטי העדכני ושולח /model claude-opus-4-8 לעצמו

אמור: "נקה את הסשן הזה"
מבקש אישור, ואז שולח /clear לעצמו, מאפס את השיחה

אמור: "הסתר את הפרויקט הזה"
כותב .claudemux-ignore כדי שהפרויקט לא יופיע ברשימות -L

אמור: "הגן על הסשן הזה"
כותב .claudemux-protected ומגדיר את סימון tmux - כיבוי דורש עכשיו --force

אמור: "האם הסשן הזה מוגן"
בודק אם קיים .claudemux-protected בתיקיית הפרויקט ומדווח

אמור: "מחק את פרויקט old-prototype"
מאשר בצ'אט, ואז מעביר את תיקיית הפרויקט לפח המערכת

אמור: "שנה את שם הפרויקט הזה ל-my-new-name"
עוצר את הסשן, משנה שם תיקייה, מעביר היסטוריית שיחות, מפעיל מחדש

אמור: "שמור את זה כתבנית בשם web"
מעתיק את AGENTS.md (או CLAUDE.md) ל-~/.claude-mux/templates/web.md

אמור: "check agents migration" / "migrate to AGENTS.md"
מדווח (לקריאה בלבד) אילו קובצי CLAUDE.md אפשר להעביר ל-AGENTS.md; לאחר אישור משנה את שמם בכל העץ ומפעיל מחדש את הסשנים הפעילים תחת תיקיית הבסיס

אמור: "tip"
מציג טיפ - אותו טיפ כל היום, או אקראי אם TIP_MODE=random מוגדר

אמור: "הפעל טיפים" / "כבה טיפים"
מפעיל או מכבה את הטיפ היומי בכל הפרויקטים

אמור: "עדכן claude-mux"
מזהיר שכל הסשנים יופעלו מחדש, מבקש אישור, ואז מעדכן ומפעיל מחדש

אמור: "עצור את כל הסשנים"
סוגר בצורה מסודרת את כל הסשנים המנוהלים

אמור: "help"
מציג את רשימת הפקודות המלאה
```

**פקודות אלה עובדות בכל שפה.** אם תקליד את המקבילה בעברית, ביפנית, בספרדית או בכל שפה אחרת, Claude מזהה את הכוונה ומריץ את הפקודה המתאימה.

**הקלד `help` בתוך כל סשן כדי לראות את רשימת הפקודות המלאה.**
